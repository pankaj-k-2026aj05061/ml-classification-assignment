# Deployment checklist

1. Check that the latest GitHub Actions run passed and that the five model files and `test_data.csv` are in the repository.
2. In Streamlit Community Cloud, deploy this repository from branch `main` with `app.py` as the entry point.
3. Open the public app URL and check the bundled CSV and an uploaded CSV.
4. Check the comparison table, each model's metrics, confusion matrix, classification report, and prediction download.
5. Run the notebook or training script in BITS Virtual Lab and save a screenshot showing the lab ID and results.
6. Make sure the README has the correct GitHub and Streamlit links.
7. The final assignment PDF should contain the two links, the README, and the BITS Virtual Lab evidence.
